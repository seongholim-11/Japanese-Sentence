**남은 문제와 추가 발견**

1. **[중간 · 미해결] sanitize가 불가능한 회독 상태를 허용합니다.**  
   파일: [src/progress.ts:225](/D:/personal_project/Japanese-Sentence/src/progress.ts:225), [226](/D:/personal_project/Japanese-Sentence/src/progress.ts:226)

   재현 입력:

   ```js
   {
     sets: {
       "kana:0": {
         round: 1,
         queue: ["あ", "い", "う"],
         pos: 0,
         known: 3,
         again: ["う"]
       }
     }
   }
   ```

   `sanitize` 후에도 그대로 남습니다. 이 상태에서 세 장 모두 ‘알아요’로 처리하자 실제 `mark()` 결과가 **`total: 3, known: 6, again: ["う"]`**였습니다. 결과 화면 계산상 정답률은 200%이며, 방금 맞힌 카드가 다음 회독에도 남습니다.

   `again`은 이미 처리한 `queue.slice(0, pos)` 범위로 제한하고, `known`도 처리 수·오답 수와 일치시켜야 합니다.

2. **[중간 · 미해결] 알림 복원 실패 시 OFF 표시와 실제 예약이 불일치합니다.**  
   파일: [SettingsScreen.tsx:672](/D:/personal_project/Japanese-Sentence/src/screens/SettingsScreen.tsx:672), [676](/D:/personal_project/Japanese-Sentence/src/screens/SettingsScreen.tsx:676), [reminder.ts:66](/D:/personal_project/Japanese-Sentence/src/reminder.ts:66)

   실제 함수에 OS 알림 API 대역을 연결해 재현했습니다.

   - 기존 예약 → OFF 백업 복원 → 취소 API 실패: **설정 OFF, 기존 예약 유지**

   실패 시 기존 알림 설정을 유지하거나 실제 예약 상태를 재확인하고, 사용자에게 실패를 알려야 합니다. 현재는 ‘백업을 가져왔어요’만 표시합니다.

3. **[중간 · 새 문제] 음성 검사기가 잘못된 require 경로를 통과시킵니다.**
