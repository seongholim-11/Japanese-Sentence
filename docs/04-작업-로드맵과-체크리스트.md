## 상시 규칙

- 영어 앱 폴더는 수정하지 않는다.
- 키·비밀번호·토큰을 채팅이나 파일에 적지 않는다(`.env`는 사용자가 직접 입력, `EXPO_PUBLIC_` 접두어 금지).
- 커밋·푸시는 사용자가 요청할 때만 한다.
- 결제·계정·로그인은 사용자가 직접 한다.
- 사실을 확인하지 못했으면 "확인하지 못했다"고 적는다.
