## 기본값으로 정한 것 (질문하지 않았고 필요하면 바꿀 수 있음)

- 문체: 존댓말(です・ます) 기본, 반말은 `style: "普通"`으로 표시
- 일본어 글꼴: Noto Sans JP(Bold/Medium) — 02 단계에서 한자 표시·용량을 확인하고 필요하면 교체
- 가나 덱 한글 독음은 "대략적인 안내"로 표시
- 음성: Google Cloud TTS Chirp 3 HD `ja-JP` 2종(대화문 A/B), 표제어 합성 기준(표기/읽기)은 05 단계 샘플 청취 후 사용자가 확정
- 저장 키·백업 앱 ID는 영어 앱과 분리: `lingoloop-ja/progress/v1`, `lingoloop-ja`
- 설정·세트·복습·퀴즈·백업·알림 기능은 영어 앱과 동일
