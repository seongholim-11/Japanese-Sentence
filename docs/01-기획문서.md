## 1. 한 줄 요약

한국어 사용자가 일본어 단어·문형·문장·대화문을 **카드로 여러 번 돌려 보며(회독) 익히는** 오프라인 학습 앱. 영어 앱의 구조(세트 회독, 퀴즈, 간격 복습, 오프라인 음성, 가입·광고 없음)를 그대로 가져오고, 일본어에만 필요한 **후리가나(읽기)·한자·가나** 기능을 더한다.

## 3. 대상 사용자와 목표

- **대상**: 일본어를 처음 배우거나 JLPT N5~N3 수준에서 단어·표현을 꾸준히 반복하고 싶은 한국어 사용자. 앱 화면(UI)은 한국어.
- **핵심 약속**: "잊을 때쯤 다시 나와요"(간격 복습 1·3·7·14·30일), "인터넷 없이 듣는 일본어 발음", "가입도 광고도 없이".
- **하지 않는 것(v1)**: AI 대화·말하기 채점·마이크 사용, 계정·서버, 한자 쓰기 필기 인식, 커뮤니티.

## 5. 영어 앱에서 그대로 쓰는 것

- 세트 회독(10·20·30·50·100장 선택), "알아요/다시 볼래요", 한 바퀴 후 모르는 카드만 다음 회독
- 간격 복습(박스 0~5, 1·3·7·14·30일), 헷갈린 카드 복습, 직전 채점 취소
- 퀴즈(세트당 최대 10문제) — **단, 출제 로직은 일본어용으로 교체**(6장 참고)
- 오프라인 음성(미리 생성한 mp3 포함) + 기기 음성 대체, 발음 속도 조절, 자동 재생, 대화문 전체 듣기
- 검색·즐겨찾기, 기록(연속 학습일), 알림, 백업 내보내기·가져오기, 설정 페이지 구조, 테마·글자 크기
- 저장값 검증(sanitize)·테스트 스크립트 방식, 출시 문서 구조(`docs/`, `site/`)

## 6. 일본어에서 새로 필요한 것 (핵심 설계)

1. **후리가나(읽기) 표시**
   - 카드 앞면: 표기(한자 포함)만 크게. 뒷면에서 읽기·뜻·예문을 보여 준다.
   - 설정 "읽기 표시": ① 항상 ② 뜻 보기 후 ③ 숨김. 대화문·예문에서도 같은 설정을 따른다.
   - 표시 방식 제안: 한자 위에 얹는 루비 대신 **문장 아래 한 줄 읽기**(구현이 쉽고 React Native에서 안정적). 루비 레이아웃은 v1.1 후보.
2. **일본어 글꼴**
   - 영어 앱은 IBM Plex Sans KR + Space Grotesk. 일본어 한자는 한국어 글꼴로 그리면 글자 모양이 다르거나 빠질 수 있어서 **일본어 글꼴(예: Noto Sans JP 또는 IBM Plex Sans JP)** 을 명시해 불러온다. 글꼴 로딩 실패 시 기본 글꼴로 시작하는 기존 폴백은 유지.
3. **퀴즈 재설계** (영어식 빈칸 문제는 못 쓴다 — 띄어쓰기가 없고 동사·형용사가 활용한다)
   - 뜻 고르기(일본어→한국어), **읽기 고르기**(한자→히라가나), 한국어→일본어 고르기, 빈칸 채우기는 데이터에 빈칸 위치를 **미리 표시한 예문만** 출제.
   - 오답 보기는 같은 품사·같은 레벨에서 뽑고, 뜻이 겹치지 않게 한다(영어 앱에서 겪은 문제).
4. **검색 정규화**: 한자·히라가나·가타카나·한국어 뜻으로 모두 검색. 히라가나로 검색하면 한자 단어도 나오게 읽기 필드를 색인. 전각/반각, 가타카나↔히라가나 정규화.
5. **음성(TTS)**: Google Cloud TTS **Chirp 3 HD는 일본어(ja-JP)를 지원**한다([공식 문서](https://docs.cloud.google.com/text-to-speech/docs/chirp3-hd)). 다만 ja-JP 음성 이름 목록은 이 기획 단계에서 확인하지 못했다 → 개발 때 `list-voices`로 확인. 한자의 다의 읽기(行った, 生, 日 등)는 합성이 틀릴 수 있어서 **단어는 읽기(가나) 기준 합성 vs 표기 기준 합성을 샘플로 비교**하고, 문장은 읽기 보정 사전(SSML `sub` 등)을 둔다. 대화문 A/B는 영어 앱처럼 서로 다른 음성 2종.
6. **레벨 표기**: JLPT는 2010년 이후 공식 단어 목록을 공개하지 않는다고 알려져 있다(확인 필요). 레벨은 "JLPT 목표 수준(비공식 구분)"으로 표기하고 공식 목록이라고 주장하지 않는다.
7. **존댓말·반말 표시**: 대화문·문장에 문체 태그(丁寧/普通)를 달아 학습자가 구분하게 한다.

## 7. 콘텐츠 출처와 라이선스 (가장 위험한 부분)

영어 앱은 영단어 선정에 CC BY-SA 자료를 썼고 앱 안에 출처와 라이선스 전문을 실었다. 일본어는 사정이 더 복잡하다.

| 필요한 것 | 후보 | 확인할 점 |
| --- | --- | --- |
| 단어 목록·읽기 | JMdict(EDRDG) | EDRDG 라이선스는 출처 표기와 파생 데이터 공유 조건이 있다([라이선스 안내](https://www.edrdg.org/edrdg/license.html)). 버전(CC BY-SA 4.0 등)과 앱에 넣을 때의 의무를 출시 전 직접 확인 |
| 한국어 뜻 | **직접 작성**(AI 초안 + 검수) | JMdict에는 한국어 뜻이 없는 것으로 알고 있음(확인 필요). 시판 일한사전·교재의 뜻을 복사하지 않는다 |
| 레벨(N5~N3) | 커뮤니티 목록 참고 | 목록별 라이선스가 다르고 공식이 아님. 그대로 복사하지 말고 "참고해 직접 구성"하며 출처·조건 확인 |
| 예문 | **직접 작성**(영어 앱과 같은 방식) | Tatoeba는 CC BY 2.0 FR이라 저자 표기가 필요하다([Tatoeba 개요](https://en.wikipedia.org/wiki/Tatoeba)). 저자 표기 부담이 커서 v1은 직접 작성 권장 |
| 빈도 근거 | 자막·말뭉치 기반 빈도 | 영어 앱이 쓴 [FrequencyWords](https://github.com/hermitdave/FrequencyWords)에 일본어 목록이 있는지 **확인하지 못했다**. 없으면 JLPT 수준 + 일상 회화 중요도로 구성 |
| 음성 | Google Cloud TTS | 합성 음성 고지(영어 앱과 동일), 비용·무료 한도 확인 |

- 모든 외부 자료는 `NOTICES.md`와 앱 설정 > 출처·라이선스에 출처·조건을 싣는다.
- 법적 판단이 필요한 부분(파생 데이터 공유 범위 등)은 출시 전에 따로 검토한다. 이 문서는 법률 자문이 아니다.

## 9. 성공 기준 (v1.0)

- 기능: 영어 앱과 같은 학습 흐름 + 읽기 표시 설정 + 가나 덱.
- 품질: 모든 일본어 문장·읽기·뜻을 **2단계 이상 검수**(자동 읽기 대조 + 사람 또는 다른 모델 교차검수). 오류 신고 0건 목표는 아니지만 알려진 오류는 출시 전 0.
- 성능: 첫 실행 속도, 용량(음성 mp3 약 7,100개, 약 40MB 안팎 예상 — 추정).
- 접근성·작은 화면: 영어 앱에서 겪은 문제(글자 크기, 작은 iPhone, 한 손 조작)를 처음부터 반영.
- 출시 문서: 개인정보처리방침·지원 페이지(영어 앱과 같은 구조), 스토어 문구, 스크린샷, 연령 등급 설문 답변.
