# 문장 (sentences)
- front: 한국어(해요체 구어), ja: 일본어 정답, reading: 가나, note: 핵심 표현 풀이 한 줄(`いくら = 얼마`), style, level.
- 한 문장은 하나의 핵심 표현(단어 또는 문형)을 연습하도록 설계하고, 그 표현 id 를 `uses` 배열에 적어(검수용).
- 한국어를 보고 일본어로 **하나의 자연스러운 정답**이 나오는 문장만. 정답이 여러 개로 갈릴 수 있으면 note 에 허용 변형을 적거나 문장을 바꿔.
- 길이 8~30자, 일상 회화. 존댓말 기본, 반말은 style "普通" 로 표시.

# 대화문 (dialogue)
- 6줄, A/B 교대(A 가 먼저). speaker 는 일반적인 직함·관계(店員, 友達, 駅員, 同僚 등). B 는 "나(학습자)" 시점으로 쓰고 speaker 를 `私` 로.
- 각 줄: ja, reading, ko. 한 줄 40자 이하, 자연스러운 구어체(필러 えっと, あの 는 적당히). 문체(존댓말/반말)는 대화 전체에서 일관되게, 의도적인 전환은 title 이나 주석으로 표시.
- expressions: 대화에서 배울 만한 표현 2~4개. **전부** 단어·문형 덱 또는 용어집(expressions.ts)에 뜻·예문이 있어야 해. 없으면 용어집 항목(표현, 뜻, 예문, 예문 해석, 읽기)을 같이 만들어.
- 대화는 이야기가 이어지도록(질문→대답→되묻기→마무리), 마지막 줄은 대화가 자연스럽게 끝나게.
- 일본 문화에 맞는 표현(경어, 인사)을 쓰되 고정관념·편견을 담지 마.

# 공통 금지
- 비속어, 성적·폭력적 묘사, 정치·종교 논쟁, 실존 인물·상표(예: 편의점 이름 대신 コンビニ), 차별 표현.
- 모르는 일본어 표현을 지어내지 마. 확신이 없으면 빼고 `review: true`.
