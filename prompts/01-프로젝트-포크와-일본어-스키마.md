# 01. 프로젝트 포크와 일본어 스키마 (M1)

전제: `00-마스터-프롬프트.md`의 컨텍스트와 규칙을 이미 읽었고, 사용자가 `docs/DECISIONS.md`의 결정(앱 이름, Bundle ID, 가나 덱 포함 여부 등)을 확정했다.

````
M1 단계를 진행해 줘. 목표는 "영어 앱을 복사해 일본어 스키마로 바꾸고, 가나 덱과 샘플 단어 20장만 있는 가장 작은 일본어 앱이 타입 검사를 통과하고 실행되는 것"이야.

# 입력
- docs\DECISIONS.md 의 확정된 값(앱 이름, Bundle ID, slug, 덱 구성)
- docs\02-데이터-명세와-콘텐츠-계획.md 의 스키마(2장)
- docs\03-기술-변경-목록.md

# 작업
1. 복사: D:\personal_project\English-Sentence 를 D:\personal_project\Japanese-Sentence 로 복사하되 제외 항목은 docs\03 의 "0. 복사 방법"을 따라. 이미 있는 docs\ 와 prompts\ 는 덮어쓰지 마(병합). `git init`, 첫 커밋은 하지 말고 상태만 보여 줘.
2. 식별자: app.json 의 name, slug, ios.bundleIdentifier, android.package 를 DECISIONS.md 값으로 바꿔. extra.eas.projectId 와 owner 는 영어 앱 값이 남아 있으면 지워(사용자가 `eas init`을 새로 실행할 거야). package.json name 도 바꿔.
3. 저장 키·백업 분리: progress.ts 의 STORAGE_KEY 를 `lingoloop-ja/progress/v1` 로, backup.ts 의 BACKUP_APP 을 `lingoloop-ja` 로 바꿔(영어 앱 백업을 일본어 앱에 가져오지 못하게). 백업 파일명도 바꿔.
4. 데이터 타입: src/data/decks.ts 의 Card 타입을 docs\02 의 스키마(2-1~2-5)에 맞게 확장해(reading, exReading, level, style, blank, note). 덱 ID 를 words / patterns / sentences / kana / dialogue 로 정리하고, 이 ID 를 쓰는 모든 곳(progress.ts, quiz.ts, search.ts, 모든 screens, App.tsx, weak.ts)을 빠짐없이 고쳐. 변경 전에 `grep`으로 사용처를 전부 찾아 목록을 보여 줘.
5. 대화문 타입: Line 을 { who, speaker, ja, reading, ko } 로 바꾸고 사용처를 고쳐.
6. 데이터 비우기: 영어 단어·구동사·문장·대화문 데이터와 CMUdict/FrequencyWords 관련 코드·고지를 제거해. 대신 아래 샘플만 넣어.
   - 가나: 히라가나 청음 あ행~わ행 일부(10장 이상), 가타카나 일부(5장 이상)
   - 단어 20장: 일상 N5 단어(食べる, 飲む, 水, 学校 등)를 스키마 전체 필드와 함께, 예문·읽기·한국어 뜻을 직접 써서
   - 문형 3장, 문장 5장, 대화문 1편(6줄)
   샘플은 정확해야 해. 확신이 없는 항목은 넣지 마.
7. 영어 전용 코드 정리: 영어 발음기호·CMUdict 관련 설명, 영어 문구("영단어", "구동사", "English")가 화면과 문서에 남아 있는지 grep 해서 목록을 만들고 이번 단계에서는 화면 문구만 일본어 앱 용어로 바꿔(퀴즈·검색·음성 로직은 02 단계에서 다룸 — 지금은 컴파일만 되게 최소 수정).
8. 검증: `npm install`, `npm run typecheck` 통과. 음성은 아직 없으므로 manifest 는 빈 객체여도 컴파일되게 만들어. 로컬 웹(`npm run web`)이 뜨는지 확인해(가능하면 브라우저로 홈·덱·카드 화면을 열어 에러 없음 확인).
````
