````
# 검수 대상
- 〈덱〉 데이터: 〈파일 경로〉 〈범위, 예: 전체 / id 앞 100개〉
- 스키마와 규칙: D:\personal_project\Japanese-Sentence\docs\02-데이터-명세와-콘텐츠-계획.md

# 검수 항목 (모든 항목에 대해 id 와 함께 근거를 적어)
1. 표기·읽기 오류: front/ja 와 reading/exReading 이 일치하는가. 한자 읽기 오류, 조사 は/へ/を 변환 오류, 장음·촉음·탁음 오류, 가타카나 외래어 표기.
2. 일본어 자연스러움: 어색한 표현, 부자연스러운 어순·조사, 실제로 잘 쓰지 않는 표현, 문체(丁寧/普通) 불일치, 경어 오류.
3. 레벨 적합성: 예문 안의 어휘·문법이 표시한 level 보다 어렵지 않은가(예: N5 예문에 N3 문형).
4. 한국어 뜻·해석 정확성: 오역, 부자연스러운 직역, 뜻 누락(다의어의 가장 흔한 뜻), 존댓말·반말 일치.
5. blank: 예문에 한 번만 포함되는 정확한 활용 형태인가, 빈칸으로 만들었을 때 정답이 하나로 정해지는가.
6. 콘텐츠 안전: 비속어, 차별, 성적·폭력·정치·종교 민감 표현, 실존 인물·상표. 연령 등급 설문에 영향을 줄 낱말 목록(술·담배·약물·폭력 낱말)도 따로 뽑아.
7. 중복·유사: 거의 같은 예문, 같은 뜻의 중복 카드, 오답으로 쓰이면 정답과 겹칠 만한 뜻 쌍(퀴즈 품질).
8. 일관성: tag/level/style 표기, 용어(한국어 품사명), 한국어 말투.
9. 대화문(해당 시): A/B 교대, 6줄, 이야기 흐름, 마지막 줄, expressions 설명 연결, 문체 일관성.

# 방법
- 자동 검증 스크립트(scripts\validate-content.cjs)를 먼저 돌려 결과를 보고해. 그다음 사람이 읽듯이 항목을 검토해.
- 전수 검토가 어렵면 무작위 표본(최소 30%)과 오류가 잘 나는 유형(한 글자 한자, 동음이의어, 활용형, 敬語)을 우선해서 보고, 어디까지 봤는지 정확히 적어.
- **확신이 없는 판정은 "확신 없음"으로 표시해.** 원어민 확인이 필요한 항목 목록을 따로 만들어.

# 출력 형식
- 심각도(높음: 틀린 일본어·뜻, 중간: 어색함·레벨 불일치, 낮음: 표기 일관성) 순 표: id | 문제 | 제안 수정 | 근거
- 요약: 검토 범위, 오류율 추정(검토한 개수 대비), 가장 흔한 오류 유형 3가지, 수정 후 다시 검수가 필요한 id 목록
````
